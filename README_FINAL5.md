# Hensem FINAL5 PRO

本版只做后台交互和安全会话修正，不修改业务数据统计口径。

## 业务页面
- 三方量进入后立即显示完整国家导航。
- 默认日期仍为昨天。
- 选择国家 / 日期 / 条件后，点击「查询」才读取 Supabase。
- 不再显示正常状态下的：
  - 当前结果
  - 条件已修改
  - 数据已齐
  - 历史补齐中
  - 冗长的表格操作说明
- 真正的读取失败/回退异常仍会显示异常提示。
- 自动出款、提现操作人、工单、客服、三方费率继续保持手动查询。

## 1小时无操作退出
修复旧版问题：Supabase 会话每45分钟刷新一次，旧实现会因此把1小时 idle timer 重新开始计算。
FINAL5 改为：
- 真实鼠标/键盘/触摸/滚动才算活动；
- token 自动刷新不算活动；
- 每30秒检查一次；
- 页面从后台恢复、电脑休眠后回来也立即检查；
- 连续1小时没有用户操作会清除登录会话并返回登录页。
