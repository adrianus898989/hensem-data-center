# Hensem FINAL3 — 合并模块版

这版按原始 v239 ZIP 的模块结构恢复，不拆模块：

- 「提现 / 自动出款统计」只有一个左侧入口
  - 模块内部切换：自动出款 / 提现操作人
- 「工单 / 客服」只有一个左侧入口
  - 模块内部切换：工单 / 客服
  - 工单内部仍保留工单统计、操作人统计等原业务页面
- 「三方量 / 费率」保持一个入口

本版只调整布局/UI和模块入口，不改现有统计口径、表格字段、Supabase数据逻辑。

同时：
- 取消“快照月份”按钮行
- 移除长说明副标题
- 保留日期/平台筛选、KPI、表格、导出等现有数据显示
- 管理后台权限也把“工单 + 客服”合并成一个勾选项
- IP白名单、账号搜索、日志搜索保留
- 8月起自动出款/提现操作人继续走现有 Supabase 同步逻辑
