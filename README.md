# Hensem 数据后台 — 2026-08-09 一次部署整合版

这一个前端包包含此前尚未上线的全部修改：

1. 三方量
- 删除“日汇总 / 月汇总”切换。
- 选 1–5 号，直接显示 1–5 号累计。
- 选整月，直接显示整月累计。
- 点“查看”显示所选日期范围全部明细。
- 查看弹窗表头可排序。
- 删除“来源”列。
- 国家盘口页签切换只切 UI，不自动查询。
- 切国家盘口时立即响应，不再因为隐藏费率大表和手续费重算卡数秒。
- 三方量金额、笔数统计逻辑不改。

2. 三方费率展示
- “代收状态 / 代付状态”读取 Google 左侧对应状态。
- 右侧各盘口矩阵只用于“接入平台”详情。
- 两种状态不再混用。

3. 自动出款 / 提现操作人
- 模块仍保持合并，不拆分。
- 8 月起查询按实际日期从 Supabase 读取，不先读整月。
- 4–7 月历史快照继续只读。
- 自动同步仍使用现有 24L + SQL37，不需要重建。

4. 登录
- 保留严格 1 小时无真实操作自动退出逻辑。

Supabase bright-responder 请配套使用同一部署包中的 bright-responder.ts。
