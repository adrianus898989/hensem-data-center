# Hensem FINAL4 — 业务模块统一手动查询

本版在 FINAL3 合并模块 UI 基础上，只改交互，不改业务统计口径。

## 统一规则
- 三方量 / 费率：进入不自动查询，日期默认昨天，点击查询后才显示数据。
- 提现 / 自动出款：进入不自动查询，日期默认昨天，点击查询后才读取 Supabase。
- 工单 / 客服：进入不自动查询，日期默认昨天，工单和客服各自点击查询后才读取。
- 快捷日期、上一日/下一日、重置：只修改查询条件，不会自动发请求。
- 已查询页面仍可对当前查询区间做原有的静默定时刷新。
- 管理后台 / IP 白名单 / 操作日志 / 个人资料保持进入即加载。
- 取消业务页面的快照月份行。

## 不变
- 自动出款 / 提现操作人不拆模块。
- 工单 / 客服不拆模块。
- 三方量聚合逻辑、费率逻辑、自动出款与操作人口径、工单/客服统计字段不改。
